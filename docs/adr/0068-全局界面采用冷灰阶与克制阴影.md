# 全局界面采用冷灰阶与克制阴影

Lithe 的应用表面、选中态、悬浮态、边框、焦点环和品牌标识统一使用黑、白、灰
构成的冷灰阶，不以浅蓝色或其他彩色作为全局主色。红、黄、绿等颜色只用于错误、
警告、成功、运行状态等语义反馈；终端 ANSI 色和代码编辑器语法高亮不受全局灰阶
限制，以保持信息辨识度。浅色主题的应用壳层与侧栏使用近白和浅冷灰表面，正文
接近黑色，终端继续使用深色。已有的浅色、深色与跟随系统三种主题选择保持不变
并继续持久化；浅色和深色主题都采用冷灰阶，只替换各自的视觉值。

界面通过表面明度、边框和克制阴影表达层级。窗口化应用外框使用轻微、宽扩散阴影，
弹窗、浮层和右键菜单使用更明确的悬浮阴影；左侧栏、标签组与普通面板主要依靠
背景明度差和边框分层，不分别添加阴影。最大化状态移除应用外框阴影。
