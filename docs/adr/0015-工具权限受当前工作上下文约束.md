# 工具权限受当前工作上下文约束

Agent 中的 `lithe-tool` 调用受启动时绑定的当前项目、工作区、任务和实例约束：
工作区工具不能越出当前项目，任务工具不能越出当前工作区，Agent 工具不能越出
当前任务。外部终端则必须显式传入从 `context` 查询到的稳定目标 ID。删除任务或
工作区等不可逆操作始终由 Lithe UI 取得用户确认；可恢复的任务归档可以直接执行，
但运行中的任务除外。运行状态是例外：`task running` 和 `task idle` 只接受当前
Code Agent 的 capability，不接受目标 ID，也不允许外部终端调用。布局与终端不向
`lithe-tool` 暴露。
