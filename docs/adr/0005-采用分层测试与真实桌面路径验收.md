# 采用分层测试与真实 Electron 路径验收

Lithe 采用三层验证：main 与数据库使用 Vitest node 测试，renderer 使用 Vitest、jsdom 和 Testing Library 测试用户交互，跨进程行为使用 Playwright Electron E2E。renderer 单测可直接 Mock 类型化的 `window.lithe`，但 E2E 必须使用真实 preload、IPC 和 SQLite，并通过独立临时 `userData` 隔离数据。

任意代码或配置至少运行格式、lint 和适用 typecheck；renderer 或 main 变更再运行对应单测与 build，IPC、持久化、导航、主题或启动流程必须补 E2E。安装包或平台配置还要在目标系统构建并对解包应用或安装产物做启动冒烟；测试通过只代表适用影响面的证据完整，不能用 Mock 路径替代真实消费者路径。
