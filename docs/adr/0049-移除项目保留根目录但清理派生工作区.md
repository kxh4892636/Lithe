# 移除项目保留根目录但清理派生工作区

移除项目时，Lithe 保留用户选择的项目根目录和根目录当前分支，但删除所有由
Lithe 创建的派生 Worktree 目录及其分支；外部 Worktree 继续完全忽略。每个工作树
必须已停止且干净，包含未合并提交的分支必须展示摘要并要求用户输入完整分支名
二次确认，任何 `lithe-tool` 请求都不能绕过这些门禁。

全部文件系统清理成功后，Lithe 永久删除该项目所有工作区、任务、Agent 会话 ID、
布局和状态历史；任一步骤失败则保留 SQLite 记录供修复重试。以后重新添加同一路径
会生成新项目 ID，不恢复旧历史。

这条保留规则同样适用于 Lithe 在 `~/.lithe/projects/` 或开发版对应目录中创建的
托管空白项目。根目录之后可能包含用户代码，不能因其最初由 Lithe 创建就在移除
项目时自动删除。
