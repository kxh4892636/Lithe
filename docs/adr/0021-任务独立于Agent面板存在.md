# 任务独立于 Agent 面板存在

中间主界面以面板作为布局叶节点，面板可组成标签组并递归进行水平或垂直拆分，
类型包括 Agent、普通终端、文件编辑和 Git Diff。Agent 面板引用任务，且同一任务
最多打开一个；关闭面板只移除视图，不删除或归档任务，也不停止 CLI，用户可从
左侧任务列表重新打开或聚焦它。点击左侧任务时始终聚焦对应 Agent 面板：Agent
正在运行时只聚焦；尚无 Agent 会话时自动启动全局默认 Adapter；已有可恢复会话
时自动恢复。启动或恢复失败仍保持面板聚焦，并在面板内展示错误状态。普通终端
则不归属于任务。Agent 面板不提供启动、恢复、停止或 Fork 工具栏；任务 hover
操作行只显示可用的 Fork 和归档，其中运行中的任务禁用归档；停止只在运行中任务
的右键菜单显示。
