# 任务独立于 Agent 面板存在

中间主界面以面板作为布局叶节点，面板可组成标签组并递归进行水平或垂直拆分，
类型包括 Agent 和普通终端。Agent 面板引用任务，且同一任务
最多打开一个；关闭面板只移除视图，不删除或归档任务，也不停止 CLI，用户可从
左侧任务列表重新打开或聚焦它。点击关闭任务时打开对应 Agent 面板，并启动或
恢复 Code Agent，成功后进入空闲；点击空闲或运行中的任务只聚焦，不改变状态。
启动或恢复失败时任务保持关闭，面板继续展示错误。普通终端不归属于任务。

Agent 面板不提供启动、恢复、停止或 Fork 工具栏；任务 hover 操作行显示可用的
Fork 和归档，运行中的任务禁用两者。停止在空闲或运行中任务的右键菜单显示；
停止成功后任务进入关闭并移除 Agent 面板，失败时保留原状态和面板并展示错误。
