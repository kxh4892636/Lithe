# Agent 面板重挂载以尺寸抖动触发重绘

切换工作区时中间主界面目前整体卸载并重建（这与 ADR 0022「切换只改变可见
性」的意图存在偏差，布局常驻留作后续演进）。重挂载的 Agent 面板是一个健康
但完全空的终端：架构不做输出回放（ADR 0052），主进程 PTY 只转发不缓冲，
而面板重挂载时计算出的尺寸通常与 PTY 当前尺寸相同，同尺寸 resize 不派发
事件，终端因而永远收不到内容、呈纯黑；只有布局变化带来的真实尺寸变化才能
恢复。实测表明：ConPTY 在真实尺寸变化时会向终端重放其屏幕缓冲（无需 CLI
参与）。据此决定：Agent 面板挂载并完成 onResize 订阅后，强制一次真实尺寸
抖动（行数先减一、约 120ms 后恢复），借 ConPTY 的缓冲重放恢复画面；CLI
未运行时不抖动。曾考虑渲染进程滚动缓冲回放（还能还原滚动历史）与主进程
缓冲加回放 IPC（契约改动最大），均因改动面大而放弃；若日后需要滚动历史
回放，应重新评估缓冲方案并淘汰本抖动。
