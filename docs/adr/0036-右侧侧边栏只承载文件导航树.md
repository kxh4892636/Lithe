# 右侧侧边栏只承载文件导航树

文件编辑器与 Git Diff 正文都属于中间主界面，右侧侧边栏只显示项目文件树或 Git
变更文件树，不承载编辑、预览或 Diff 正文。右侧侧边栏不提供全屏操作，也不会
占据中间主界面；两侧共同工作但拥有清晰的内容与导航职责。

侧边栏以用户手动切换的“文件”和“变更”标签呈现，并按工作区保存选择、展开
状态、滚动位置与宽度；无 Git 工作区只显示文件树。点击文件条目会在中间主界面
当前活动标签组中新建文件编辑面板，点击变更条目则新建对应 Git Diff 面板；
无论相同文件是否已经打开，都不复用或聚焦已有面板。

右侧侧边栏的新工作区默认打开“文件”标签；宽度、开关、当前标签、树展开与滚动
状态均按工作区独立持久化。关闭后中间主界面占用释放宽度，相关操作只由 UI 与
键盘快捷键提供。侧边栏关闭时，几何位置最靠右上方的标签组在标题栏最右侧、
该组新建终端按钮之后显示恢复侧边栏的操作；布局拆分变化时，该操作跟随新的
右上标签组，侧边栏打开后隐藏。
