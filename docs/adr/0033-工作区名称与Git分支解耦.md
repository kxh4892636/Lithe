# 工作区名称与 Git 分支解耦

工作区以稳定 ID 标识，并拥有独立、可重命名的显示名称；默认工作区初始显示为
“默认”，派生工作区初始可采用新分支名。Git 分支只作为次要信息展示，外部切换
或重命名分支不改变工作区身份与名称，重命名工作区也不修改分支或移动 Worktree
目录，从而保持布局、任务与置顶引用稳定。

工作区标题采用单行格式：正常分支显示为 `<Git 分支> - <工作区名称>`；无 Git
项目只显示工作区名称；detached HEAD 显示为
`HEAD@<短提交哈希> - <工作区名称>`；Git 状态暂时不可读或工作区无效时也只显示
工作区名称并沿用无效状态样式。
