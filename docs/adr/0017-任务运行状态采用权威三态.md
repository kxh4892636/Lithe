# 任务运行状态采用权威三态

一个任务同一时刻只有一个 Code Agent，其运行状态由主进程维护的关闭、空闲或
运行中三态字段唯一决定，Renderer 不再组合终端进程与运行标记推断状态。创建、
启动、恢复或 Fork 成功后进入空闲；当前 Code Agent 通过 capability 绑定的
`task running` 和 `task idle` 幂等切换运行中与空闲；停止、正常退出、意外退出
或启动失败后进入关闭。

`task running` 与 `task idle` 不接受任务或实例参数，失效 capability 的迟到请求
会被拒绝。Lithe 启动时先将遗留状态归为关闭；自动恢复成功后进入空闲，不能继承
上次的运行中。该单一权威状态避免界面把“终端已打开”误报为“Code Agent 正在
工作”，也避免多个来源互相覆盖。
