# Agent 派生与工作区派生相互独立

fork Agent 会话只在当前工作区创建一个新任务和独立的派生 Agent 会话，并在源
Agent 面板旁打开标签；它不创建 Git 分支或 Worktree，也不停止源任务。派生工作区
则只负责建立新的分支和工作目录，不隐式复制 Agent 上下文，从而避免复制对话与
隔离文件这两种不同副作用被绑定成一次操作。

Fork 允许源任务处于空闲或关闭，且不改变源任务状态；源任务运行中时，hover
操作区和右键菜单中的 Fork 保持可见但禁用。Lithe 不为执行 Fork 自动停止源任务。
Fork 成功后，新任务打开 Agent 面板并进入空闲；只有新 Code Agent 显式调用
`task running` 后才进入运行中。失败时不留下不完整的新任务。
