# 以稳定项目身份隔离派生工作区

Lithe 为首次加入的项目生成稳定项目 ID，并将派生工作区保存到
`~/.lithe/worktree/{project-name}-{project-id短码}/{工作区名称}`。相比仅使用
项目名称，这一结构仍便于人工识别，同时避免不同根目录下的同名项目发生冲突；
项目改名或移动不会改变其身份。

创建项目时，项目名称默认采用所选已有文件夹的 basename，但用户可以在创建浮窗
中修改；它只是显示名称，不改变项目根目录。创建空白项目时未选择 Source folder，
Lithe 才使用项目名称在托管项目目录下创建新的根目录。

不同项目允许使用相同显示名称，Lithe 不在导航标题中自动追加路径或编号。项目
始终由稳定项目 ID 标识；只有项目选择器、冲突提示等确实需要消歧的界面才在名称
之外补充根目录。

Source folder 在创建项目记录前必须规范化并解析为真实目录路径；Windows 下路径
比较不区分大小写。同一真实目录只能对应一个项目。用户再次选择已加入的目录时，
Lithe 直接定位并聚焦已有项目，不创建新的项目 ID，也不以不同路径拼写、符号链接
或目录联接制造重复项目。

Lithe 只识别并管理自己创建在该目录下的派生工作区；仓库中由其他工具或用户
创建的外部 Worktree 不发现、不展示、不导入，也不执行任何操作。
