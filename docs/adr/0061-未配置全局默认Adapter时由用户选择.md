# 未配置全局默认 Adapter 时由用户选择

尚未配置全局默认 CLI 时，Lithe 检测用户当前已有且可用的内置 Adapter，并要求
用户从结果中亲自选择一个。候选集合包含内置 Codex CLI、内置 Claude Code，以及
用户已经创建且通过可用性校验的自定义声明式 Adapter。即使只有一个可用项也不
自动确定；选择结果持久化为全局默认值，后续启动不得重新选择，也不得因可用
集合变化而静默改变默认值。

用户后续可以在设置中显式将全局默认值改为其他可用 Adapter；变更只影响新任务。

Lithe 不在应用首次启动时强制选择。用户可以提前在设置中配置；否则在首次创建
任务时展示选择界面，并在用户完成选择前不创建任务。没有可用 Adapter 时，该
界面只展示检测原因与官方安装指引。
