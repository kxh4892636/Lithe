# 任务创建允许一次性选择 Adapter

创建任务时同时填写任务名称并选择 Adapter；选择器默认采用全局默认 CLI，但用户
可以为本次创建改选其他可用 Adapter。该选择只绑定新任务的不可变 Adapter 版本，
不产生项目级或工作区级默认值；未配置全局默认值时仍由用户显式选择后才能创建。

选择器只显示当前可用的 Adapter，可视区域固定为五个子项并在超出时内部滚动。
候选按稳定 `adapterId` 的使用次数从高到低排列；次数相同时全局默认值优先，其余
按显示名称排序。每次成功创建非 Fork 任务后为所选 Adapter 累计一次，启动、恢复、
Fork 和删除不改变计数，Adapter 产生新版本时沿用原身份的累计值。
现有任务没有可靠的 Fork 来源记录，因此升级时所有 Adapter 计数从零开始，不按
当前任务数量近似回填。

全局默认 Adapter 可用时初始选中该项；全局默认值未配置或当前不可用时不自动选择
其他候选，必须由用户显式选择。没有可用候选时禁止创建并提供进入设置的操作，
不得静默回退到其他 Adapter 或创建无法启动的任务。

全局 `lithe-tool task create` 提供可选的 `--adapter-id <id>`；显式传入时绑定指定的
可用 Adapter，省略时沿用全局默认值，且不改变界面焦点。该参数不增加新命令，
通过工具成功创建的非 Fork 任务同样累计对应 Adapter 的使用次数。

这取代了 ADR-0019 中“创建任务只能使用全局默认 CLI”的限制，在维持单一全局默认
和任务 Adapter 版本不可变的前提下，允许用户按任务选择不同的 Coding Agent。
