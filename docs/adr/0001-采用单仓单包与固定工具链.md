# 采用单仓单包与固定工具链

Lithe 采用单 Git 仓库、单 pnpm package 的 Electron 桌面应用形态，不拆分子仓、workspace 子包或独立后端服务。仓库根同时承担依赖安装、开发、测试和构建入口，并固定 Node.js 24 与 pnpm 11；这让 main、preload、renderer 和 shared 契约在一次变更中同步演进，代价是各进程不能独立发布。

代码质量以 Oxfmt 和 type-aware Oxlint 为事实源，TypeScript 分别通过 node 与 web 配置检查。所有代码和配置变更至少经过格式、lint 与适用的 typecheck，避免不同进程边界各自形成不一致的工具链。
