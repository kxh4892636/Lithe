# 顶部导航兼作平台标题栏

顶部导航横跨应用全宽并同时承担窗口拖拽区域，Lithe 自身只放置导航切换操作；
其左、中、右区域分别与左侧导航、中间主界面和右侧文件树对齐，空白区域不增加
动态标题或业务操作。最小化、最大化与关闭继续使用平台原生窗口按钮，双击空白
导航区域在最大化与窗口化之间切换，业务面板不侵入标题栏命中区域。

应用壳层在普通窗口状态使用 `12px` 圆角、清晰的 `1px` 冷灰边框和轻阴影，并裁剪
内部表面。最大化与系统分屏属于贴边状态，取消圆角和外框阴影；系统分屏仍保留
应用内部的 `1px` 冷灰边界。首次启动以屏幕工作区宽高的 61% 居中显示，并受
`480 × 360` 最小尺寸约束；此后恢复用户保存的位置、尺寸与最大化状态。窗口进入
系统分屏区域时，严格适应系统分配的边界，但不得因此自动改变左、右侧栏的展开
或隐藏状态；两侧栏只受用户操作控制。退出时始终保存窗口当下的实际位置和尺寸，
无论边界来自用户自行调整还是系统分屏；下次启动恢复这组边界，但不承诺恢复由
Windows 管理的分屏组关系。内容区下方保留横跨全宽、首版无内容的紧凑 Footer。
Windows 与 Linux 的原生窗口控制覆盖区和导航栏固定为 44px 高，使原生按钮 hover
区域等宽等高并保持垂直居中；透明窗口
不叠加会填满外框的原生背景材质，窗口化壳层使用清晰边框标示边界。

设置页进入同一壳层后，以包含返回操作和分类导航的设置侧栏替换项目侧栏，不同时
显示两条左侧栏；顶部导航切换操作控制当前页面的侧栏。设置侧栏与项目侧栏共享
同一展开或隐藏状态，页面切换只替换侧栏内容，不创建第二套折叠偏好。

业务按钮、弹窗、浮层、选择器等基础控件优先使用 shadcn/ui。shadcn 组件只能通过
仓库内 CLI `pnpm exec shadcn add <component>` 获取或更新，不手写、复制或另行维护
一份同名组件实现。
