# 项目或工作区目录缺失时只标记无效

项目根目录或其磁盘在原绝对路径不可用时，Lithe 将项目标记为无效，禁止恢复
工作区、启动 Agent 或执行项目管理操作；不扫描磁盘、不提供重新定位，也不能把
原项目 ID 绑定到其他路径。需要替换为不同目录时，必须移除原项目并重新添加。

派生工作区目录缺失或不可用时，只将该工作区标记为无效，禁止启动或恢复其中的
Agent；保留工作区、任务、Agent 会话 ID 与布局记录，不自动重建 Worktree，也不
重新定位。Agent 面板显示“工作区目录不存在”，不暴露 PTY 的原始系统错误码；
用户仍可从工作区右键菜单移除无效工作区。

Lithe 在启动、窗口重新获得焦点和用户刷新时检查项目与工作区原路径；同一路径
恢复后自动取消无效标记并保留历史，但不立即启动 Agent，直到用户重新进入对应
工作区。
