# Renderer 采用代码路由与分层状态架构

Renderer 采用 React、TanStack Router 的代码路由与 hash history，并由应用壳统一承载导航和页面出口。启动、应用壳、路由、i18n 和全局样式统一放在 `src/renderer/src/app`；领域页面、状态、单元测试和 Playwright E2E 按归属放在 `features/<domain>`，shadcn UI primitive 留在 `components/ui`，业务语义不能下沉到通用组件层。

异步读取由 TanStack React Query 管理，跨组件客户端状态由 Zustand 管理，用户可见文案通过 i18next 读取，主题最终通过 IPC 持久化到 main 的 SQLite。该分工避免路由、远端式异步状态、本地交互状态和持久化状态混为一体；代价是新增页面或状态时必须明确其所属层，并同步维护路由、导航、文案与测试。
