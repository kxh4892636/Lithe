# 普通文件夹不自动初始化 Git

普通文件夹作为无 Git 项目加入 Lithe，只拥有默认工作区，且不能派生
Worktree。Lithe 不把它虚构为 `main` 分支，也不提供或自动执行 `git init` 与初始
提交；新建项目同样只创建普通文件夹。用户通过终端或 Coding Agent 自行初始化并
产生首个提交后，Lithe 自动检测并启用派生工作区能力，从而避免桌面工具改变目录
的版本控制状态。

安装版新建的空白项目默认位于 `~/.lithe/projects/<项目名称>`，开发版默认位于
`~/.lithe-development/projects/<项目名称>`。该目录创建后作为项目根目录和默认
工作区，不包含 `.git`，也不自动产生其他文件。

“创建项目”浮窗始终要求项目名称，并允许选择至多一个 Source folder。选择后直接
把已有文件夹作为项目根目录，不复制内容；未选择时才创建上述托管空白目录。

空白项目名称还必须是当前平台合法的单级目录名，拒绝路径分隔符、`.`、`..`、
Windows 保留名及非法字符。目标目录已存在时创建失败，不自动追加数字或复用；
用户必须修改名称，或通过 Source folder 把该目录作为已有文件夹加入。选择已有
文件夹时，项目显示名称只要求非空，不受目录名规则限制。
