# 左侧导航磨砂材质允许平台降级

只有左侧导航使用能透出 Lithe 外部背景的磨砂材质，Windows 与 macOS 优先采用
平台原生背景效果；Linux compositor 不支持、系统降低透明度、远程桌面或图形
能力不足时允许退化为主题色半透明或不透明背景。中间主界面与右侧侧边栏保持
实色以保证终端和 Diff 可读，视觉透明也不产生鼠标穿透。

左侧导航的宽度与固定展开或关闭状态在应用级持久化，首次启动默认展开；关闭时
完全隐藏并释放布局宽度，不保留缩窄图标栏。悬浮顶部导航中的切换图标时，导航
只作为覆盖层临时展开且不落盘，点击则持久打开。点击切换图标关闭导航时必须立即
完全隐藏，即使指针仍停留在图标上也不进入临时覆盖层；只有指针先离开图标并再次
移入，才重新允许悬浮展开。项目和置顶工作区分组各自保存折叠状态。
