# 正常启动自动恢复已打开的 Agent

Lithe 正常启动时只恢复当前可见工作区的布局，并为其中仍打开 Agent 面板的活跃
任务自动恢复 Agent；其他工作区直到用户首次选中时才执行相同恢复。已有 Agent
会话 ID 时由 Adapter 执行恢复命令，尚无 ID 时重新执行新会话启动命令；关闭面板
或归档任务不会启动 Agent，单个失败不阻塞其他任务。若上次为崩溃或强制终止，
则先展示一次恢复确认，避免自动进入重复崩溃循环。

工作区一旦恢复，切换到其他工作区只改变中间主界面的可见性；其中的 Agent、PTY
和普通终端进程继续后台运行，再次选中时复用现有进程而不重复恢复。
