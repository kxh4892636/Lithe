# 移除右侧侧边栏与文件编辑和 Git Diff 能力

Lithe 曾由右侧侧边栏承载工作区文件树与 Git 变更树，并以其为唯一入口在中间
主界面打开文件编辑面板与 Git Diff 面板。产品判断这套导航与编辑能力不是当前
工作环境所需要的：用户文件浏览、编辑与 Diff 审阅交给 Coding Agent、终端和
外部编辑器完成，Lithe 聚焦于 Agent 会话与终端的组织。因此整体移除右侧侧边栏、
文件编辑器、Git Diff 面板及其专属的文件与 Git Diff 主进程服务和 IPC，中间
主界面只承载 Agent 与终端面板。

**Consequences**：已持久化的布局快照中可能仍含 file 与 git-diff 类型标签，布局
水合时静默丢弃，不做数据库迁移；按工作区保存在 localStorage 的侧边栏状态键
随之废弃，不做清理。若未来重新引入文件浏览或 Diff 能力，需要重新决策入口与
归属，不应假设恢复旧的右侧侧边栏形态。
