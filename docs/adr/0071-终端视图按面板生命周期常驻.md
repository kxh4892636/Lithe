# 终端视图按面板生命周期常驻

普通终端与 Agent 面板共用一个终端视图模块。面板存在期间，该模块以 `panelId`
维持同一个 xterm 实例、输入输出订阅和尺寸同步；React 重渲染、任务内容更新与
工作区切换只改变数据或可见性，不得重挂载终端视图。普通终端和 Agent 仍分别
保留各自的 PTY 所有权与启动、关闭语义。

终端面板不可见时仍持续消费 PTY 输出，并更新 xterm 有容量上限的进程内
scrollback；再次显示时直接呈现最新画面，不执行补录或重放。

Agent 的运行、空闲、停止与恢复只改变交互能力和状态展示，不参与终端视图
身份。Agent 停止后保留最后画面；恢复时复用同一终端视图，任务运行状态变化
不得触发 xterm 重建。

普通终端同样只以 `panelId` 定义终端视图与当前 PTY 的身份。`cwd`、`shell`
的路径归一化或等价配置对象更新只更新持久化启动参数，不得重启当前会话；
需要不同启动参数时新建终端。

普通终端标签拥有完整终端会话。关闭标签时终止 shell 及其完整子进程树，并
销毁 PTY、xterm、输入输出订阅和内存 scrollback；关闭后的 `panelId` 彻底
失效。Agent 标签只是任务的视图，关闭标签不得停止 Agent 进程或 PTY。

Agent 终端由任务而非标签拥有。Agent 标签关闭后，同一个 xterm、输入输出订阅
和内存 scrollback 在后台继续消费 PTY 输出；重新打开该任务的 Agent 面板时
挂接原终端视图，并立即显示标签关闭期间产生的输出。

显式停止 Agent 时终止进程树和 PTY、移除 Agent 面板标签，但保留任务拥有的
xterm 最后画面供重新打开后恢复复用。归档任务、删除任务或退出应用时，才销毁
Agent 的 xterm、输入输出订阅和内存 scrollback；归档后恢复按 ADR 0016 创建新的
PTY 和终端视图。

该决定落实 ADR 0022 中工作区切换只改变可见性的约束，并取代 ADR 0070 依赖
ConPTY 尺寸抖动重放屏幕缓冲的补偿方案。终端视图模块不保存或回放输出，应用
退出后的语义仍由 ADR 0052 约束。

曾考虑保留两个终端实现并分别稳定 React 依赖，或在主进程、渲染进程增加输出
缓冲；前者继续复制容易分叉的生命周期逻辑，后者扩大 IPC 与敏感输出存储边界，
均不采用。
