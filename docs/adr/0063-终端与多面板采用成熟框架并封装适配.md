# 终端与多面板采用成熟框架并封装适配

WS02 使用 `node-pty` 作为本机 PTY Adapter，Windows 走 ConPTY，Linux 与 macOS 走
Unix PTY；使用 `xterm.js` 与官方 `addon-fit` 作为 Renderer 终端模拟和尺寸适配；
使用 `flexlayout-react` 承担递归 tabset、拆分、拖拽移动、空组收拢与临时最大化。

三类框架分别位于 PTY 运行时、终端视图和面板布局 seam 后。Lithe 自己只维护稳定
面板身份、工作区归属、权限校验、SQLite 持久化映射和产品命令，不复制框架的终端
协议、拖拽或通用布局算法。持久化保存 Lithe 可迁移的布局快照与终端启动参数，
不保存终端输出；框架运行时对象不得进入数据库或 IPC 契约。

选择依据：

- 三者均为 MIT 许可证，API 能覆盖首版需求而无需 fork。
- `node-pty` 明确支持 Windows ConPTY 与 Unix PTY，并被 VS Code 等桌面工具使用。
- `xterm.js` 提供稳定公共接口及官方尺寸适配插件。
- `flexlayout-react` 支持 React 19、递归 tabset、移动、拆分和最大化。

若框架 JSON 模型或事件发生变化，只替换对应 Adapter 和持久化映射，不改变工作区
布局与终端生命周期的领域接口。
