# electron-vite 构建与 electron-builder 交付分工

Lithe 由 electron-vite 构建 main、preload 和 renderer 到 `out`，再由 electron-builder 只装配 `out`、生产依赖、`package.json`、`LICENSE` 和 `drizzle` migrations 到 `dist`。限制安装包文件范围可避免测试、配置和源码意外进入 `app.asar`，而 migrations 必须作为外部资源保留供生产启动读取。

交付目标为 Windows x64 NSIS、Linux x64 AppImage 和 macOS x64/arm64 DMG，CI 在三大桌面系统运行质量门禁并分别产出安装包，Windows 额外执行真实 Electron E2E。首版产物不签名、不公证、不自动发布；这是当前本地底座阶段的范围约束，若进入公开分发，必须重新决策证书、notarization、更新与发布通道。
