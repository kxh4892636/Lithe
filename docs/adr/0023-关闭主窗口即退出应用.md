# 关闭主窗口即退出应用

Lithe 首版不驻留系统托盘，Windows、Linux 和 macOS 关闭主窗口都表示请求退出。
存在运行中任务时先展示任务清单并取得确认，用户取消后保持应用与任务原状；
空闲和关闭任务不要求确认。确认退出后保存布局并关闭全部 Code Agent 与 PTY，
空闲任务下次可按仍保留的 Agent 面板自动恢复为空闲。操作系统强制终止无法经过
该流程，下次启动按异常退出处理并在恢复 Agent 前再次确认。

正常退出时，主进程必须先允许渲染进程提交最后一次可见任务与工作区布局状态，
并等待窗口渲染生命周期结束，再注销 IPC handlers、关闭服务和数据库；不得在
React 卸载清理仍可能调用 IPC 时提前移除 `tasks:set-visible`、
`workspace-layouts:save` 等 handler。退出期间的最后一次保存应可重复执行且不产生
“No handler registered” 错误。
