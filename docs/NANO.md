lithe UI 分为四部分，顶部导航，左侧导航，中间主界面，右侧侧边栏
顶部导航：左侧只有一个「切换」icon，用于左侧导航的关闭/打开，关闭状态下悬浮在上面，同样会展开左侧导航
左侧导航：顶向下，依次为Lithe app ICON，工具栏，置顶会话，项目管理，无项目的任务会话，app信息栏：例如设置等
中间主界面：windows/linux/mac 的三端终端，可以任意的垂直/水平无限拆分
右侧侧边栏 ：包含git diff 审阅界面和文件浏览器，其中两者内部又可以分为左侧编辑和右侧文件导航。右侧侧边栏可以全屏，点击全屏后占据中间主界面+右侧侧边栏的位置。

项目管理是根据一个文件夹作为根目录，可以新建或使用一个已有的文件夹，一个项目可以创建多个会话
会话状态具有「已读，未读，运行中，归档，删除」
